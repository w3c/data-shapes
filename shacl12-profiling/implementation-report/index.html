KAI Semantic Background (KAISB)

Who
KurrawongAI
Homepage
https://github.com/kurrawong/semantic-background
Report date
2026-09-15
Description

KurrawongAI's Semantic Background is a Knowledge Graph of reference Semantic Web resources used by KurrawongAI to supplement domain Knowledge Graphs and non-semantic information.

The Semantic Background contains ontologies, vocabularies and validators, many of which are organized using classes and properties defined by [[[dx-prof]]].

Some of the validators are sh:ShapesGraph instances that contain SHACL elements packaged according to [[[shacl12-profiling#packaging]]].
