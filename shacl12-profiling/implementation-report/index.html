Implementations

This section lists implementors of [[[shacl12-profiling]]].'s features listed in [[[#features]]].

VocPub Profile of SKOS (VocPub)

Who
Australian Government Linked Data Working Group
Homepage
https://linked.data.gov.au/def/vocpub/validator
Report date
2026-09-24
Description

The Australian Government Linked Data Working Group is a working group / community of practice in Australia that promotes the use of Linked Data.

The Working Group maintains a few Semantic Web assets for Australian government and wider community the VocPub Profile of SKOS which is profile of [[[skos-reference]]] created according to the [[[dx-prof-1.0]]] contains several resources that have been created using [[[shacl12-profiling]]] features.

The primary reason for VocPub's adoption of [[[shacl12-profiling]]] features is that there are three shapes graphs within the profile's resources - a main one and two extensions that build on it. By using features of [[[shacl12-profiling#packaging]]], the dependent validators can import and reuse shape definitions in the main one and then extend on them, rather than having to reiterate them.

A secondary reason for the adoption of SHACL 1.2 Profiling elements is that VocPub contains simple shapes for basic catalogue-style metadata for Concept Schemes, such as name, description, created data and so on which, when described using these elements, can be reused by other validators looking to test for the same elements, perhaps on difference classes of focus node. For example, the similar OntPub Validator targets simple metadata for OWL ontologies and it reuses lots of VocPub property shapes to do so.

KAI Semantic Background (KAISB)

Who
KurrawongAI
Homepage
https://github.com/kurrawong/semantic-background
Report date
2026-09-15
Description

The Semantic Background is a Knowledge Graph of reference Semantic Web resources used by KurrawongAI to supplement domain Knowledge Graphs and non-semantic information.

The Semantic Background contains ontologies, vocabularies and validators, many of which are organized using classes and properties defined by [[[dx-prof-1.0]]].

Some of the validators are sh:ShapesGraph instances that contain SHACL Elements packaged according to [[[shacl12-profiling#packaging]]].

Also implemented is a profile of the [[[shacl12-profiling#union-profile]]] which just contains additional annotation properties for SHACL Elements and several null profiles of W3C ontologies.
