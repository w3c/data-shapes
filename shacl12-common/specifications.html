SHACL Specifications

This specification is part of the SHACL 1.2 family of specifications. See the SHACL 1.2 Overview for a more detailed introduction to them.

The specifications are as follows:

Working Drafts:

[[[shacl12-core]]]
defines the Core of SHACL
[[[shacl12-node-expr]]]
defines expressions used to derive focus nodes and value nodes in SHACL
[[[shacl12-sparql]]]
defines SPARQL-related extensions of SHACL
[[[shacl12-inference-rules]]]
defines SHACL's framework of rule-based inference
[[[shacl12-profiling]]]
defines the use of SHACL for profiling data, including SHACL data
[[[shacl12-ui]]]
defines SHACL's use for User Interface generation
[[[sparql12-rl]]]
defines a Datalog-style rules language for RDF that can be used with SHACL 1.2 Inference Rules

Editor's Drafts:

SHACL 1.2 Overview
overviews the set of SHACL specifications
SHACL 1.2 Compact Syntax
defines an RDF syntax for expressing SHACL concepts

Implementers can partially check their level of conformance with the above specifications by testing themselves with the test cases each presents, linked to in their metadata. Note, however, that passing all the tests in a test suite does not imply complete conformance to the specifications, it only implies that the implementation conforms to the aspects tested by the test suite.
