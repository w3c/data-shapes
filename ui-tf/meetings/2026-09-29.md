## Agenda

### Topic: Conformance discussion

What do we think about this as a middle ground?

> Conformance in SHACL UI is defined with respect to the features an implementation claims to support.
>
> A _feature_ is a named set of normative requirements identified in this specification. A
> _conformance claim_ is an explicit statement of which features the implementation supports.
> 
> An implementation that claims support for a feature MUST satisfy the normative requirements for that
> feature and for any features it depends on. An implementation is not required to support a feature
> for which it makes no conformance claim.

Goal: Reach consensus in the task force on what conformance means for SHACL UI.

If the goal is not met by the end of this week, the competing positions will be presented to the wider
WG in next Monday's call, with the vote on the final decision to be made in the Monday following.
