### Topic: Conformance discussion

What do we think about this as a middle ground?

> Conformance in SHACL UI is defined with respect to the features an implementation claims to support.
> An implementation that claims support for a feature MUST satisfy the normative requirements defined
> for that feature and any features on which it depends. An implementation is not required to support
> a feature for which it makes no conformance claim.
