## Minutes

### Shapes Scoring and Logic

#### Proposal
- Add shapes to the textual form of the evaluation of the score logic and make them the primary definition. The score would be attached as a property to the shape.
- Separate widgets and score shape. Separating the widget from the score shape would simplify overwriting the default widgets. The link from the score shape to the widget would get an order property so that multiple links can be created.

**Summary**: This proposal decouples scoring logic from widgets and introduces a new set of customizable shapes to link scores to widgets.
