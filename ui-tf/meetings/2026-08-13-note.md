# PR Review Activity Analysis

All timestamps below are UTC, taken directly from the GitHub API (`created_at` / `submitted_at` fields).
Sources: `gh api repos/w3c/data-shapes/pulls/{1121,1118,1112}`, their `/reviews`, `/comments`, and `/timeline` endpoints, plus issue #1083 and PR #1104/#1133.
Merge-blocking status and CI checks come from `gh pr view --json reviewDecision,mergeStateStatus,statusCheckRollup`.

**Method for the "blocked by the hold comment" durations below:** the review submitted with the text "Requesting changes to hold this PR until the ..." is a distinct thing from bergos's other, substantive change-request reviews (e.g. the terminology review on #1118).
A duration below counts only the time during which (a) that specific hold-comment review was the current, unsuperseded review from bergos, and (b) at least one other reviewer's approval was already in place — i.e. the window during which the PR would, counterfactually, have been mergeable if the hold-comment review alone were removed.
Time is excluded once bergos submits a different (non-hold-text) change-request review, since removing the hold review at that point would not have changed mergeability, and time is excluded entirely if no other reviewer has ever approved, since the PR could not have merged regardless of bergos's review.
Durations are given both as raw calendar time and as working days/hours (Saturday/Sunday excluded).
