## Specification updates

PR: https://github.com/w3c/data-shapes/pull/885

Add `<dfn>` tags for the following SHACL UI concepts:

* SHACL Renderer
* Node UI Component
* Property UI Component

Action: Edmond to update the specification.

Use the ReSpec `<dfn>...</dfn>` pattern. Example from SHACL Core:

```html
<dfn data-plurals="focus nodes" id="dfn-focus-node" tabindex="0" aria-haspopup="dialog" data-dfn-type="dfn">focus node</dfn>
```

The term can then be referenced using its `id`, for example:

```html
<a href="#dfn-focus-node">focus node</a>
```

Reference: [https://respec.org/docs/#define-a-term](https://respec.org/docs/#define-a-term)
