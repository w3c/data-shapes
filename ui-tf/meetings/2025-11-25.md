### SHACL UI Protocol Discussion
The group agreed that the SHACL UI specification should not define or promote a specific protocol for persisting data.
However, the specification should define declarative mechanisms for describing the shape of data to be fetched—for example:
- Populating the focus node of a SHACL Renderer (e.g., using CBD or symmetric CBD).
- Providing data required by widgets, such as drop-down items for an AutoComplete field (data fetched using shapes).

#### Key Considerations
